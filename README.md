# Orangesoft website (static mockup)

Static HTML/CSS/JS mockup: Home, Lightning-fast website, Add-ons, Pricing, About, FAQ, Contact and Free website score. No build step.

## Run locally
Open `index.html`, or run `python3 -m http.server 8000` in this folder.

## Publish on GitHub Pages
Settings > Pages > Deploy from branch > `main` / root.
