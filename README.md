# Orangesoft website (static mockup)

Static HTML/CSS/JS mockup of the Orangesoft site: Lightning-fast Website, Add-ons, Pricing, About, FAQ, Contact and Free Website Score. No build step.

## Run locally
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000

## Publish on GitHub Pages
Repository Settings > Pages > Deploy from branch > `main` / root.

## Pages
- `index.html` Home
- `why-headless-page.html` Lightning-fast Website
- `solutions-page.html` Add-ons
- `pricing-page.html` Pricing
- `about-page.html` About
- `faq-page.html` FAQ
- `contact-page.html` Contact
- `audit-page.html` Free Website Score
